# CP3406 Gacha Pull Simulator & Tracker

## App Purpose

This app is a utility-style gacha pull simulator and tracker. It helps users quickly simulate gacha pulls, view their latest result, track pity count, total pulls, pull history, and change banner settings.

## Core Features

- Pull 1 character
- Pull 10 characters
- Track pity counter
- Track total pulls
- View pull history
- Choose different banner types
- Toggle high rate demo mode
- Toggle character image display
- Reset pull history
- Load character data from a GitHub JSON API using Retrofit

## Technologies Used

- Kotlin
- Android Studio
- Jetpack Compose
- Material Design 3
- ViewModel
- Repository pattern
- Retrofit
- GitHub version control
